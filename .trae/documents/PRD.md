# 青贮饲料管理分系统移动端APP - 产品需求文档

## 1. 产品概述

青贮饲料管理移动端APP是安徽省粮食安全监测监管信息系统的移动端补充，面向种植户和乡镇经办人，重点解决田间地头现场填报和离线操作需求，实现种植计划申报、进度跟踪、受灾申报、地图展示等核心功能的移动化操作。

- 目标用户：种植户（田间填报）、乡镇经办人（代办核实）、县级管理员（查看审核）
- 核心价值：离线填报 + 自动同步 + 点面结合地图展示 + 便捷移动交互

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 种植户 | 管理员分配账号 | 填报种植计划、上报进度、查看地图、受灾申报 |
| 乡镇经办人 | 管理员分配账号 | 代办填报、进度核实、地图查看 |
| 县级管理员 | 管理员分配账号 | 数据查看、审核状态跟踪 |
| 市级管理员 | 管理员分配账号 | 数据查看、统计分析 |

### 2.2 功能模块

1. **首页**：用户信息、种植概况、待办事项、离线数据状态、快捷功能入口
2. **任务管理**：种植计划申报列表、新增/编辑种植计划、地块信息编辑
3. **一张图**：地图展示（点面结合）、图层控制、主体/地块弹窗详情
4. **进度跟踪**：进度列表、进度填报（生长信息+现场照片）
5. **受灾申报**：受灾申报列表、受灾申报填报（含时限预警）
6. **离线数据管理**：同步状态、未同步数据列表、同步历史
7. **统计分析**：个人种植概况、地区统计摘要、趋势图
8. **个人中心**：个人信息、设置、操作日志、关于

## 3. 核心流程

### 3.1 种植计划申报流程

用户打开任务管理 → 点击新增 → 填写基本信息 → 添加地块 → 上传附件 → 暂存草稿或提交审核 → 离线时保存到本地 → 联网后自动同步

```mermaid
flowchart TD
    "打开任务管理" --> "点击新增"
    "点击新增" --> "填写基本信息"
    "填写基本信息" --> "添加地块信息"
    "添加地块信息" --> "上传附件(可选)"
    "上传附件(可选)" --> "选择操作"
    "选择操作" --> "暂存草稿"
    "选择操作" --> "提交审核"
    "暂存草稿" --> "保存到本地"
    "提交审核" --> "判断网络状态"
    "判断网络状态" --> "在线: 直接提交"
    "判断网络状态" --> "离线: 标记待提交"
    "离线: 标记待提交" --> "联网后自动同步"
```

### 3.2 进度填报流程

用户进入进度跟踪 → 查看整体进度 → 点击填报 → 选择地块 → 填写生长信息 → 拍照上传 → 保存或提交

### 3.3 受灾申报流程

用户进入受灾申报 → 点击新增 → 填写灾害信息 → 拍照上传（必填）→ 填写收储信息 → 提交审核 → 系统根据时限自动预警

### 3.4 离线同步流程

```mermaid
flowchart TD
    "检测网络状态" --> "联网"
    "联网" --> "检测未同步数据"
    "检测未同步数据" --> "有未同步数据"
    "检测未同步数据" --> "无未同步数据"
    "有未同步数据" --> "批量上传"
    "批量上传" --> "上传成功"
    "批量上传" --> "上传失败"
    "上传成功" --> "清理本地数据"
    "上传失败" --> "标记失败,支持重试"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色**：#1A5C9A（深蓝色，顶部导航、按钮主色）
- **辅色**：#2E7D32（绿色系，体现青贮饲料特征）
- **警示色**：#E6A23C（待审核、待处理）
- **危险色**：#F56C6C（灾害预警、异常数据）
- **成功色**：#67C23A（操作成功、已完成）
- **背景色**：#F5F7FA
- **卡片色**：#FFFFFF
- **离线状态色**：#909399
- **按钮风格**：全宽高度48px圆角按钮，主按钮填充色，次按钮描边
- **字体**：系统默认字体，标题16px加粗，正文14px常规，辅助12px
- **布局风格**：移动端单列卡片布局，底部Tab导航
- **图标风格**：Lucide线性图标

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | 用户信息区 | 白色卡片，头像+姓名+地区，左侧对齐 |
| 首页 | 种植概况 | 双列数据卡片，大数字+小标签 |
| 首页 | 待办事项 | 卡片列表，左侧色条标识优先级，右侧操作按钮 |
| 首页 | 快捷功能 | 2×2网格图标入口，圆形图标背景 |
| 任务列表 | 筛选标签 | 横向滚动标签栏，选中态填充色 |
| 任务列表 | 任务卡片 | 白色卡片，编号+品种+面积+状态标签+时间 |
| 种植计划申报 | 表单 | 分组卡片，每组有标题图标，输入框全宽48px高 |
| 一张图 | 地图 | 全屏地图，右下角图层控制按钮，底部统计条 |
| 进度列表 | 进度条 | 彩色进度条，百分比文字 |
| 统计分析 | 趋势图 | Recharts折线图，渐变填充 |
| 个人中心 | 设置列表 | 分组列表项，右侧开关/箭头 |

### 4.3 响应式设计

- 移动端优先设计，适配375px-428px宽度
- 底部导航栏固定56px高度
- 顶部导航栏固定56px高度
- 内容区域可滚动
- 所有触控目标最小44px×44px

### 4.4 离线状态提示

- 离线时顶部显示红色提示条"离线模式 - 数据将保存在本地"
- 同步中显示绿色提示条+进度条
- 同步完成显示绿色提示条+已上传条数
